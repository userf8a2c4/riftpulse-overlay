## 🚀 Instalar

**🖥 Extensión:** [Agregar a Chrome](https://chromewebstore.google.com/detail/bkdmpcokjfgpnmkfnccgkakdincidoba) (Chrome, Edge, Brave y Opera). Un clic y se actualiza sola.

**📱 App:** [abrila](https://userf8a2c4.github.io/riftpulse-overlay/app.html); en el celu se puede agregar a la pantalla de inicio.

**🎥 OBS:** en la [página](https://userf8a2c4.github.io/riftpulse-overlay/#stream) elegí cómo se ve y copiá la URL → en OBS, **Fuentes → + → Navegador**, pegala, **1920 × 1080**.
- Para co-streams, el **mínimo**: `overlay.html?modo=minimo` (la barra y solo las peleas 5v5 que importan).
- **Tu chat contra el modelo:** sumá `&canal=tu_canal`.
- Todos los parámetros: [docs/obs-parametros.md](docs/obs-parametros.md) · para que todo tu chat lo vea sin instalar nada: la [Extensión de Twitch](docs/twitch-extension.md) (en preparación).

<details>
<summary>Instalar la extensión a mano (sin la tienda)</summary>

1. [Descargá el ZIP](https://userf8a2c4.github.io/riftpulse-overlay/descargas/riftpulse-extension.zip) y extraelo.
2. `chrome://extensions` → **Modo de desarrollador** → **Cargar descomprimida** → la carpeta **riftpulse-extension**.
3. En **Detalles**, activá **Permitir scripts de usuario**: así se actualiza sola.

</details>

## 🧠 Cómo calcula

Una regresión logística por minuto, entrenada con juegos profesionales 2025–26. Usa el oro, las kills, las torres, los dragones (y el alma), el Barón, los inhibidores, el draft y la fuerza de cada equipo.

| Momento | Antes del juego | Min 10 | Min 15 | Min 20 | Min 25 |
|---|:---:|:---:|:---:|:---:|:---:|
| **Acierto** | 62 % | 68 % | **75 %** | 79 % | 84 % |

<sub>Medido en 589 juegos que el modelo no vio. En octubre de 2026 se reentrenó con 4.805 juegos y se confirmó en 691 juegos nuevos de 2026. Nivel, CS, wards e ítems no mejoraron la predicción, así que el modelo se quedó como está. Detalle en <a href="https://userf8a2c4.github.io/riftpulse-overlay/como-funciona.html">Cómo funciona</a>, con simulador incluido.</sub>

**Todos los juegos de este Mundial, a la vista:** qué decía el modelo a los minutos 10, 15 y 20 y quién ganó, en la [página de precisión](https://userf8a2c4.github.io/riftpulse-overlay/precision.html).

<details>
<summary><b>🛠 Para desarrollar</b></summary>
<br>

Hace falta Node, Playwright con Chromium, y Python 3 con Pillow y ffmpeg. Las mismas pruebas y el linter corren solos en GitHub con cada cambio ([Pruebas](.github/workflows/pruebas.yml)). El detalle de cada prueba está en [`pruebas/README.md`](pruebas/README.md).

Después de cambiar algo en `fuente/`, `app.js`, `app.css`, `engine.js`, `rp-ui.js` o `rp-i18n.js`, se arma todo lo que se publica (la extensión, `app.html`, `ext-overlay.js` y lo de `descargas/`):

```bash
python3 fuente/construir_extension.py
```

Las 16 baterías de pruebas, con un simulador del feed y videos generados:

```bash
node pruebas/todas.js
```

Las imágenes de la documentación y la wiki:

```bash
node pruebas/imagenes.js
```

La ficha de la Chrome Web Store (capturas y promocionales, en español y en inglés):

```bash
node pruebas/ficha-tienda.js
```

Las capturas de la página y la carta para Nick:

```bash
node pruebas/captura-extension.js
```

El GIF de este README:

```bash
node pruebas/gif.js
```

</details>
