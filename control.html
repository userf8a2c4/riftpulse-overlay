Cargando partidos…
En OBS, añade overlay.html?view=predicciones como Browser Source. Cuando un partido termina, cada pick se marca solo como acierto o fallo y se suma al marcador de aciertos.
Para que controle el overlay en OBS: añade esta página como Dock de navegador personalizado (Ver → Docks → Docks de navegador personalizados) y el overlay como Browser Source. Comparten el mismo navegador y se sincronizan solos.
